# VS01 — Rencana Eksekusi Bertahap

Untuk pelaksana: gunakan skill executing-plans; jalankan tahap secara berurutan dan buktikan hasil sebelum melanjutkan. Persetujuan eksekusi berasal dari pesan Reiner: “Baik, implementasikan satu per satu”.

Tujuan: menghasilkan prototype teknis VS01 3–5 menit sesuai rancangan yang sudah dibahas.
Arsitektur: satu place, satu pemain per server untuk prototype, progres resmi di server, narasi dan kamera di client; movement Roblox dipakai kembali.
Teknologi: Roblox Studio, Luau, Script Sync bawaan; tanpa framework tambahan.
Spesifikasi: `docs/superpowers/specs/2026-10-18-1965-tujuh-perspektif-design.md`.

## Batas global

- Target cloud: Place ID 97995024632294, Universe ID 10771684268.
- Jangan mengimpor atau menimpa `1946.rbxl`; asalnya belum terbukti.
- Jangan mempublikasikan, mengubah akses experience, atau memakai aset BARA-1946.
- Jangan commit/push otomatis; repo, branch dan remote saat ini belum ada.
- Prototype menggunakan konten teknis netral/placeholder. Teks sejarah final memerlukan peninjauan; tidak ada rekonstruksi penculikan/pembunuhan.
- Backup awal harus tersedia sebelum perubahan konten Studio. Kendala UI/tool dicatat, bukan diakali dengan klaim backup yang belum terjadi.
- Tahap yang bergantung pada tindakan user menunggu hasil tindakan tersebut; pekerjaan dokumentasi yang independen tetap dapat dilakukan.

## Fokus verifikasi

- Salah target Studio: assert PlaceId sebelum setiap pemasangan/perubahan.
- Backup tidak valid: periksa file, header format Roblox, ukuran dan hash; bukti asal tetap dari ekspor target yang benar.
- Sync salah arah: gunakan satu modul probe tanpa gameplay; verifikasi teks Studio dan disk dua arah sebelum source utama.
- Progres ganda/urutan salah: uji validasi ID, jarak server, fase, serta permintaan berulang.
- Reset saat narasi/cutscene: pulihkan kamera, input dan checkpoint sesi; tidak boleh meninggalkan softlock.

## Catatan pelaksanaan

18 Oktober 2026: tahap 1 dimulai. MCP menjangkau target yang benar. Computer Use tidak mengembalikan jendela Roblox Studio, sedangkan tool input Roblox hanya untuk Client saat playtest. Ekspor lokal memerlukan tindakan manual di menu Studio. Nama menu dikoreksi menjadi File → Download a Copy untuk place cloud berdasarkan dokumentasi resmi. Tahap 2 belum dimulai karena cadangan belum terverifikasi.

18 Oktober 2026, 17:09 WIB: tahap 1 selesai. User mengonfirmasi ekspor; berkas ditemukan dengan nama berakhiran `.rbx.rbxl` dan dipindahkan ke nama yang direncanakan tanpa overwrite. Header RBXL biner valid, ukuran 86.761 byte, SHA256 tercatat pada metadata. File belum dibuka ulang untuk uji pemulihan. Hash `1946.rbxl` tetap sama. Tahap 2 dimulai; belum ada gameplay.

Tahap 2: folder Shared, Game, dan GameClient sudah dibuat pada target Studio; folder src/shared, src/server dan src/client tersedia di disk. SyncProbe memiliki teks awal identik di kedua sisi. Studio versi 0.743.0.7431133. Menunggu user mengaktifkan Sync to pada ketiga folder. Kesamaan awal berasal dari pemasangan manual melalui MCP dan disk, sehingga belum dihitung sebagai bukti sinkronisasi. Gameplay belum dipasang. Pemeriksaan ulang Git tetap melaporkan bukan repositori; tidak ada branch/remote/commit/push.

Uji tahap 2: token Shared berhasil dua arah untuk satu script. Penambahan script pada root server/client awal tidak diterapkan; pembuatan probe dari Studio membuktikan path sebenarnya memakai subfolder Game dan GameClient. Setelah menggunakan path tersebut, uji dua arah server dan client lulus. Log Studio menjelaskan Shared root gagal karena SyncProbe di dalamnya sudah disinkron sendiri; user diminta menghentikan sync script tunggal lalu menautkan Shared root. Gameplay belum dimulai.

Ruling: ikuti path root yang dibuat Script Sync, tanpa meminta user mengulang mapping server/client — hasil dua arah sudah terbukti; biaya jika asumsi salah adalah source tidak muncul, yang diperiksa sebelum playtest. Git worktree tidak berlaku karena workspace bukan repositori; tidak menginisialisasi repo atau remote sebagai efek samping.

Tahap 2 selesai: Shared diperbaiki user dan diuji pada src/shared/Shared/Shared. Ketiga root lulus perubahan token disk ke Studio dan Studio ke disk; probe baru serta penghapusan probe juga tersinkron. Probe awal/temporer dibersihkan. Tahap 3 dimulai.

Tahap 3–4 selesai sebagai prototype teknis: test awal RED karena ChapterService belum ada, lalu 29 assertion lulus. Greybox, GameGui, prompt dan template dihasilkan BuildVS01. Source cerita tetap placeholder. Saat review ditemukan jalur kegagalan aset yang belum cukup; SceneValidation.spec RED sebelum sceneError dibuat. Setelah koreksi, Foundation 33 dan SceneValidation 12 assertion lulus.

Final: fixed loading tanpa scene, objektif hilang dan sukses palsu kamera — validasi scene/error phase, 12 regression assertions dan QA startup/runtime; suite 45/45. Tidak ada re-review kedua. Perbaikan tambahan UI sentuh diverifikasi visual dan startup tanpa PlayerModule diverifikasi pada Play baru.

Final: dua run PC berturut-turut pada kode final lulus; kamera kembali Custom. Suite final 33+12 lulus, log MessageError client/server kosong. Reset saat narasi/cutscene, missing scene/object/camera dan retry diuji. Emulator Galaxy A06 mencapai penutup dengan tombol virtual pointer dan E untuk objek. Tap ProximityPrompt/joystick fisik serta assertion joystick setelah keyboard W belum terverifikasi; lihat VS01_RESULT.md.

Ruling: PlayerModule lama tidak wajib — runtime memperlihatkan hanya RbxCharacterSounds dan GameClient pada PlayerScripts. FindFirstChild menggantikan penantian 10 detik; server tetap mengunci movement. Biaya jika runtime lain membutuhkan kontrol tambahan: uji ulang di perangkat dan pakai modul bawaan bila tersedia.

Ruling atas batas review: sejarah final, durasi, avatar, audio, save permanen, campaign dan multiplayer/streaming ditunda sesuai scope. Perangkat fisik dan FPS tidak dinyatakan lulus; emulator hanya memberi bukti UI/alur terbatas. Risiko kelayakan publikasi tema Roblox tetap terbuka.

Checkpoint final: user mengonfirmasi ekspor. Ditemukan di D:\1965-tujuh-perspektif-vs01-final.rbxl dan disalin ke backups tanpa overwrite. Ukuran 119.784 byte, header RBXL valid, SHA256 6FD2ABD3941A06985EC99431846100D51D67A0EF66DF4DC9E9A2923CDB40BC5A. Sepuluh source final cocok dengan Studio; hash file lama/cadangan awal tidak berubah. Berkas belum dibuka ulang. Git status/branch/remote tetap menyatakan bukan repositori; tidak ada publikasi.
